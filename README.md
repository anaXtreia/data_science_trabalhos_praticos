# Trabalhos Práticos — Ciência de Dados

Repositório com trabalhos práticos da Pós-Graduação em Data Science and Digital Transformation, organizados por unidade curricular.

## Estrutura

### Ambientes de Programação para Ciência de Dados

- [`P1_analise_dados_incendios.ipynb`](Ambientes_de_Programação_para_Ciencia_de_Dados/P1_analise_dados_incendios.ipynb) — análise exploratória de dados de incêndios detetados por satélite.
- [`P2_analise_previsao_situacao_academica.ipynb`](Ambientes_de_Programação_para_Ciencia_de_Dados/P2_analise_previsao_situacao_academica.ipynb) — análise e previsão da situação académica de estudantes.

### Análise de Dados e Aprendizagem Automática (ADAA)

- [`TP1_ADAA.ipynb`](Analise_de_Dados_e_Aprendizagem_Automatica/TP1_ADAA.ipynb) — trabalho prático 1.
- [`TP2_ADAA.ipynb`](Analise_de_Dados_e_Aprendizagem_Automatica/TP2_ADAA.ipynb) — trabalho prático 2.
- `dataset_PIAES_reduced.xlsx` — dados académicos usados nos trabalhos; também é utilizado no projeto 2 de Ambientes de Programação para Ciência de Dados.
- `DNA_Methylation.csv` — conjunto de dados de metilação de ADN.

### Integração de Sistemas

- [`TravelBuddy_Apresentacao.pptx`](Integracao_de_Sistemas/TravelBuddy_Apresentacao.pptx) — apresentação do Travel Buddy, uma aplicação de planeamento de viagens com integração de serviços externos.

### Tópicos Avançados de Aprendizagem Máquina (TAAM)

- [`TAAM_CNN_vfinal.ipynb`](Topicos_Avancados_de_Aprendizagem_Maquina/TAAM_CNN_vfinal.ipynb) — classificação de imagens reais e geradas por inteligência artificial com uma rede neuronal convolucional (CIFAKE).
- [`TAAM_Trabalho_NLP.ipynb`](Topicos_Avancados_de_Aprendizagem_Maquina/TAAM_Trabalho_NLP.ipynb) — classificação de mensagens SMS como spam ou ham, comparando técnicas de vetorização e modelos.
- [`TAAM_Trabalho_NLP_relatorio.pdf`](Topicos_Avancados_de_Aprendizagem_Maquina/TAAM_Trabalho_NLP_relatorio.pdf) — relatório do trabalho de NLP.

## Utilização

Os notebooks podem ser abertos com Jupyter Notebook, JupyterLab ou Google Colab. Alguns notebooks esperam que os dados estejam disponíveis em caminhos relativos ao repositório; consultar as primeiras células de cada notebook para instruções e dependências específicas.
